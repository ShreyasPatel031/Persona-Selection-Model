# Post-Intervention Recovery

**Slug:** `post-intervention-recovery`  
**Level:** meta  
**Status:** complete

## Definition

Post-intervention recovery is when a model restores suppressed behavior after an SAE intervention via reconstruction error / compensatory pathways. Limits claims that ablating identified features permanently removes a trait.
