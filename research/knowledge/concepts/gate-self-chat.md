# Gate Self-Chat Experiment

**Slug:** `gate-self-chat`  
**Level:** project  
**Status:** complete

## Definition

The gate self-chat experiment uses anonymous binary "gates" in multi-turn self-chat to discover which steering vector combinations elicit target behaviors without revealing trait names. Tests whether discovered D&D vectors compose causally in interactive settings.
